🚀 Excited to share my latest project: Micro EDA Dashboard!

I built this tool to simplify data analysis and clean up messy datasets effortlessly, and I’ve now added AI-powered insights with Google Gemini.

💡 What it does:
✅ Automates an 8-step EDA workflow on CSV and Excel files
✅ Quick checks and column type detection
✅ Missing value detection with one-click filling
✅ Categorical and numerical analysis with charts
✅ Outlier detection using boxplots
✅ AI-generated summary, data quality issues, and next-step suggestions using Gemini

🛠️ Tech Stack:
Streamlit | Python (Pandas, Matplotlib) | Google Gemini API | VS Code

🧠 Key Learnings:
🔹 Handling multiple file formats in one workflow
🔹 Integrating data wrangling, Matplotlib plotting, and the Gemini API
🔹 Prompt design: giving the LLM the right context to get useful insights
🔹 Debugging API errors after a model was retired
