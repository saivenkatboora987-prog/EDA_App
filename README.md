# EDA_App
🚀 Excited to share my latest project: Micro EDA Dashboard. I built this tool to simplify data analysis and clean up messy datasets effortlessly.
💡 What it does:
-It performs 7 steps of EDA process 
-it automates the analysis steps: "EDA workflow" or "Automated EDA process
-Gemini model:"gemini-1.5-flash"
🛠️ Tech Stack:
-Streamlit
-Python(Pandas, Matplotlib)
-VScode
🧠 Key Challenges & Learnings:
-It can handle two files extensions(CSV,EXCEL)
-Integration of Data Wrangling, Matplotlib plotting, Google Gemini API
